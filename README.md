# Proactive Business Analytics Copilot (PoC)

Ask a business question in Bahasa Indonesia or English, get a validated dashboard draft built from approved KPI definitions, have it reviewed, and publish it to a **real Tableau non-production project** with a verified URL.

> **POC / SYNTHETIC DATA.** All data is generated by `scripts/generate_synthetic.py` and is not real bank performance. This is not a compliance certification and grants no permission to connect to any bank production system. KPI definitions in the catalog are placeholders until the Business Analytics owner approves them.

## Status: what is real and what is not

| Capability | Status |
|---|---|
| Question → intent → dashboard spec → validation → preview | **Implemented and tested.** Rules-based planner; no external AI calls. |
| Synthetic dataset, semantic catalog, 7 KPI definitions (5 credit, 2 deposit) | **Implemented.** Expected values checked independently. |
| Draft editing, versioning, BA review gate, audit trail, kill switches | **Implemented and tested.** |
| Tableau REST publishing + read-back verification (TSC, PAT auth) | **Verified on a real Tableau Cloud developer site (2026.3):** publish, read-back of every view, and Tableau-rendered KPI values matching the preview. |
| Generated `.twbx` workbook | **Deterministic; accepted and rendered by Tableau Cloud.** Dashboard with key findings, KPI cards, trend with legend, labelled breakdowns. |
| Mandatory E2E (`apps/api/tests_e2e`) | **Passed against a real Tableau Cloud developer site.** It still fails by design when Tableau is missing or mocked. |
| Recurring-question recommendations (P1) | **Implemented on SIMULATED events**, behind a feature flag. |
| Adapter for an existing conversational analytics tool, production database adapter, Tableau embedding (P2) | Not implemented (out of scope). |
| SSO | Not implemented; mock login only (labelled). |

The real-Tableau E2E (PRD §3.3, §8.4) has passed on a Tableau Cloud developer site. To run it against your own site, follow [docs/runbooks/real-tableau-e2e.md](docs/runbooks/real-tableau-e2e.md).

## Quick start (local, Windows/macOS/Linux)

Requirements: Python 3.11+, Node 20+.

```bash
# 1. API
cd apps/api
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt      # macOS/Linux: .venv/bin/pip
.venv/Scripts/python -m uvicorn app.main:app --port 8000

# 2. Web (second terminal)
cd apps/web
npm install
npm run build && npm start        # or: npm run dev
```

Open http://localhost:3000 and pick a mock user. Without Tableau settings the app runs safely and shows **"Tableau integration not configured"**; publishing stays blocked.

To walk the whole flow locally before Tableau access exists, start the API in clearly-labelled mock mode. A mock publish writes the `.twbx` to `var/artifacts/` and is **never** shown as Published:

```bash
TABLEAU_ENABLED=true TABLEAU_MODE=mock FEATURE_DASHBOARD_PUBLISH=true .venv/Scripts/python -m uvicorn app.main:app --port 8000
```

Docker alternative (PostgreSQL + API + web): `cp .env.example .env && docker compose up --build`.

## Mock users

| User | Role | Can |
|---|---|---|
| `demo.business`, `demo.business2` | Business User | Ask, build drafts, publish own approved drafts |
| `demo.reviewer` | BA Reviewer | Approve others' drafts, review recommendations, access the restricted deposit dataset |
| `demo.steward` | Data Steward | Read the catalog |
| `demo.admin` | PoC Admin | Tableau connection test, kill switches, thresholds. No data access. |
| `demo.auditor` | Auditor | Read all audit events |

## Tests

```bash
cd apps/api
.venv/Scripts/ruff check app tests tests_e2e
.venv/Scripts/python -m pytest              # 106 unit/integration/security tests (mock/fake Tableau, labelled)
.venv/Scripts/python -m pytest tests_e2e -s # REAL Tableau E2E - fails unless a real site is configured
cd ../web && npm run lint                   # TypeScript type check
```

## Repository layout

```
apps/api/            FastAPI backend (Python 3.11, Pydantic, SQLAlchemy)
  app/catalog.py       semantic catalog loader + entitlements
  app/planner.py       LLMProvider interface + deterministic RulesPlanner (ID/EN)
  app/policy.py        spec + result validation (allowlists, chart rules, reconciliation)
  app/data_provider.py DataProvider interface + SyntheticDataAdapter + KPI engine
  app/dashboards.py    draft lifecycle, review, publish orchestration
  app/tableau_artifact.py  deterministic .twbx generation
  app/tableau_publisher.py TableauPublisher: REST (TSC) / mock / not-configured
  app/recommendations.py   recurring-question detection (P1)
  tests/  tests_e2e/
apps/web/            Next.js 15 + TypeScript + Tailwind + Recharts
data/seeds/catalog.json        datasets, fields, KPI definitions
data/synthetic/                generated CSVs + independently computed expected values
scripts/generate_synthetic.py  deterministic generator
docs/                          architecture, security, Tableau, product, runbooks, API
```
